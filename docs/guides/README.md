# Guias Tecnicos do StreamGate

## Objetivo

Este indice organiza os guias por dominio para acelerar onboarding e reduzir ambiguidade entre trilhas.

## Estrutura por dominio

- `platform/`: arquitetura, setup, baseline DevOps e roadmap operacional.
- `backend/`: fundacoes da API, autenticacao, OpenAPI e glossario de dominio.
- `frontend/`: fundacoes de interface e mapa oficial do workspace.
- `quality/`: Definition of Done, baseline de testes e checklist de reavaliacao.
- `security/`: baseline de seguranca e threat model.
- `operations/`: runbooks operacionais e governanca documental.
