# Product Prototypes

This directory stores approved product-design references that should remain available to future implementation and review work.

## StreamGate V3

- `streamgate-v3.html` is the approved visual reference for the authenticated StreamGate workspace.
- Treat it as a design baseline for shell density, panel rhythm, typography, navigation, chart language, spacing, and dark operational tone.
- Do not treat it as a literal DOM contract. Production UI must stay data-driven, accessible, responsive, secure, and backed by real API states.
- New SaaS/admin surfaces, especially `/settings` and connector/upload flows, should preserve this visual family unless a documented product decision replaces it.
