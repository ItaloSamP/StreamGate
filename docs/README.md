# Documentacao do StreamGate

Este diretorio esta organizado por finalidade:

- `product/`: contexto de produto, visao, escopo e direcionamento funcional.
- `guides/`: guias tecnicos e operacionais do projeto.
- `planning/`: roadmap mestre, sequenciamento de sprints e trilha executiva do projeto.
- `adr/`: registros de decisoes arquiteturais e operacionais relevantes.
- `sprints/`: closeouts oficiais por sprint.
- `superpowers/specs/`: especificacoes geradas durante fluxos de design e discovery.
